# Shivam Prajapati

AI systems engineer and independent researcher, based in India. I build tools that let AI agents work with real software, and I research alternatives to standard transformers: hyperdimensional computing, complex-valued models and mixture-of-experts. I did a BSc in Computer Science at UPEI (2026) and have about ten years of work behind me, in IT support, production and retail as well as AI.

**Open to work in India (remote preferred), available immediately.**

## Projects

| Project | What it is |
|---|---|
| [Neuro-Symbolic Cognitive Kernel](https://github.com/shiva2321/Neuro-Symbolic-Cognitive-Kernel) | CPU-native reasoning architecture on 10,240-bit hypervectors, with decision traces you can read. Python and Rust. |
| [WinTerM](https://github.com/shiva2321/WinTerM) | Windows control server for AI agents: 54 MCP tools for terminal commands, screen reading and input, with a safety gate. |
| [Hive](https://github.com/shiva2321/Hive) | Local-first memory for AI tools: collects chats from ChatGPT, Claude, Gemini, Cursor and more into one encrypted store that assistants search over MCP. |
| [Assemble](https://github.com/shiva2321/Assemble) | Assembly-code safety toolkit for AI agents (linter, auto-fixer, auditor, tracer) for x86-64, ARM64 and RISC-V. Rust. |
| [Universal SubStrait](https://github.com/shiva2321/DYNAMIC_MOE_TRANSFORMER) | Mixture-of-experts language model that adds experts for new data. 18.5x faster expert dispatch on one RTX 3060. |
| [CircuitForge](https://github.com/shiva2321/circuit_forge) | Circuit design studio with live schematic-to-VHDL sync and a logic simulator. React, TypeScript, Python. |
